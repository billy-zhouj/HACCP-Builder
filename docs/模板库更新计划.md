# 模板库更新计划：HACCP-Builder SOP 模板 × 资料库（D:\dsh\资料）

> 编制日期：本计划基于对 `src/lib/sopTemplates.ts`（26 个模板，1289 行）
> 的全文分析与 `D:\dsh\资料` 现有 5 套模板库（SC 十一项制度 12 文件、
> 记录表单 64 文件、不合格品控制 15 文件、GMP 体系 9 文件、SSOP 9 文件）
> 的素材盘点。

## 一、项目现有模板分析（26 个）

### 1.1 清单与结构特征

| 类别 | 数量 | 模板（key） |
|------|------|--------------|
| gmp | 12 | personnel_hygiene、code_of_conduct、dress_code、vendor_qualification、transportation_guarantee、sanitation、pest_control、personnel_training、corporate_structure、job_descriptions、pre_operational_inspection、preventive_maintenance |
| recall | 1 | recall（召回计划） |
| food_safety | 13 | allergen_control、raw_material_inspection、label_inspection、vendor_guarantee_coa、customer_complaints、receiving、shipping、traceability、water_potability、temperature_monitoring、supplier_verification、haccp_validation_reassessment、corrective_action_verification_records |

**结构特征**：统一 `SopTemplateDef { key/title/category/render }`；
正文为"法规依据→目的→范围→程序→监控→纠正措施→验证→记录保存"；
动态数据注入（facility/products/vendors/recallContacts/mockRecalls/
haccpTeam/productFormulations）；**5 个模板已内嵌记录表**（receiving
接收日志、shipping 发运日志、traceability 批记录、temperature 记录表、
corrective_action 纠正措施日志）——这是新增模板"内嵌表单"的既有先例。

### 1.2 注册机制

模板只需加入 `GMP_TEMPLATES`（L88）或 `FOOD_SAFETY_TEMPLATES`（L550）
数组即自动注册（L1281 导出、UI 动态列出），**无需改动其他文件**——
新增模板成本 = 一个 render 函数。

## 五、增强计划（不动已有结构，逐模板补引用/条款）

按第三节"增强"行执行，原则：
1. **补条款**：如 recall 补分级报告频次、sanitation 补消毒剂浓度核验、water_potability 补余氯监控——每条注明依据（SC-x 条款 / JL-x 表单）。
2. **补引用**：正文"记录保存"节增加对应 JL 表单编号引用（如 receiving → JL-01-01/02/07），保持"表单单一来源在资料库"。
3. **来源标注**：模板注释中标注素材来源（SC/JL/QP 编号），与资料库 README 交叉引用一致。

## 六、实现方式与工作量

1. **新增模板**：在 `GMP_TEMPLATES`/`FOOD_SAFETY_TEMPLATES` 数组追加
   render 函数（复用 fallback/formatDate/productListText 工具；记录表
   用内嵌 Markdown 表格，先例见 receiving L943-948）。
2. **数据依赖**：#1~#10 均只需现有 context 字段或 [占位符]，无需扩展
   `FacilityProfile`/types（出厂检验执行标准用 [产品执行标准] 占位，
   与项目其他模板一致）。
3. **建议顺序**：P1（3 个）→ P2（4 个）→ 增强批（约 12 处）→ P3（按需）。
   每批独立提交，便于评审。
4. **验证**：`npm run build` + lint；模板列表 UI 自动出现新项；抽查生成
   文档的法规引注与记录表渲染。
5. **工作量预估**：新模板每个 ~60-120 行 render；增强每处 ~10-30 行。

## 七、明确不做（避免重复清单）

- **不新建**：过敏原、标签、运输、组织、岗位、培训、虫害、水质、温度、
  供应链、纠正验证——已有模板覆盖，只增强。
- **不复制表单**：JL 全套 63 张表单不进入 sopTemplates——SOP 只内嵌
  "日志/记录表"（流程执行证据），表单库保持单一来源。
- **不翻译制度层**：SC 十一项制度（法规制度文件）不逐条翻成 SOP——
  项目定位是 SOP/HACCP 工具，制度条款以"法规依据"引用方式嵌入。
- **不引入新数据模型**：除非用户明确要求（如出厂检验需要产品标准库），
  新增模板一律用占位符 + 现有 context。
